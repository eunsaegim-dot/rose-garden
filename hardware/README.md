# 체감시간의 정원 — 아두이노 연동 전달 자료 (청주팀)

## 0. 현재 상태 요약

- `rose_garden_arduino.ino`: `arduino-cli` + `arduino:avr` 코어(1.8.8)로 `arduino:avr:uno` 타겟 실제 컴파일 **성공** 확인 (2026-10-18, 개발팀 Mac에서 테스트).
- 웹사이트(`serial.js` / `main.js` / `vibrationSync.js`)가 주고받는 명령 문자열이 이 `.ino`와 **전부 일치**함을 코드 대조로 확인.
- ⚠️ **아직 실제 하드웨어(버튼 배선·LED·진동 모터)로는 테스트되지 않았습니다.** 아래 4번 체크리스트로 현장에서 직접 검증이 필요합니다. (자세한 내용은 6번 참고)

## 1. 배선표

| 부품 | 보드 핀 | 연결 방법 |
|---|---|---|
| 버튼 1 (체감시간 측정 시작/종료) | **D7** | 버튼 한쪽 다리 → D7, 반대쪽 다리 → GND. `INPUT_PULLUP` 모드이므로 외부 풀업 저항 불필요. |
| 버튼 2 (전체 음악 재생 요청) | **D8** | 버튼 한쪽 다리 → D8, 반대쪽 다리 → GND. 역시 외부 저항 불필요. |
| LED (측정 상태 표시) | **D11** | D11 → 저항(220~330Ω 권장) → LED Anode(+, 긴 다리) → LED Cathode(-, 짧은 다리) → GND. **저항 없이 직결하면 LED가 손상될 수 있습니다.** |
| 진동 모터 모듈 | **D10** | D10 → 모듈의 IN(신호) 핀. 모듈 VCC/GND는 보드의 5V/GND(또는 모듈 사양에 맞는 전원)에 **별도** 연결. |

```
Arduino UNO R3
 D7  ──── [버튼1] ──── GND
 D8  ──── [버튼2] ──── GND
 D11 ──── [저항 220~330Ω] ──── [LED +]──[LED -] ──── GND
 D10 ──── [진동모터 모듈 IN]
 5V  ──── [진동모터 모듈 VCC]   (모듈 사양에 따라 조정)
 GND ──── [진동모터 모듈 GND]
```

**주의 (미검증 항목)**: 코드는 `analogWrite(D10, 200)`을 "ON", `analogWrite(D10, 0)`을 "OFF"로 가정합니다(활성-HIGH). 사용 중인 진동 모터 모듈이 반대 로직(활성-LOW)이면 `.ino`의 `VIBRATION_DUTY` 적용 부분을 반전해야 합니다. 모듈 데이터시트로 반드시 확인해 주세요 — 이 부분은 개발팀이 실제 모듈을 보지 못해 검증하지 못했습니다.

## 2. Windows Arduino IDE 설치 및 코드 업로드 방법

1. https://www.arduino.cc/en/software 에서 **Windows용 Arduino IDE**(2.x 권장)를 내려받아 설치합니다.
2. UNO R3를 USB 케이블로 Windows 노트북에 연결합니다.
3. Arduino IDE를 실행하고 `파일 > 열기`로 전달받은 `rose_garden_arduino` 폴더 안의 `rose_garden_arduino.ino`를 엽니다. (Arduino는 `.ino` 파일명과 폴더명이 같아야 하므로, 폴더 구조를 그대로 유지한 채 여세요.)
4. `도구 > 보드 > Arduino AVR Boards > Arduino Uno`를 선택합니다.
5. `도구 > 포트`에서 보드가 연결된 COM 포트를 선택합니다(어떤 포트인지 모르면 Windows 장치관리자의 "포트(COM & LPT)" 항목에서 확인).
6. 좌측 상단의 "업로드"(오른쪽 화살표) 버튼을 클릭합니다.
7. 하단 상태창에 "업로드 완료"가 표시되면 성공입니다. 실패하면 5번 "자주 발생하는 오류" 표를 참고하세요.

## 3. Chrome에서 공개 웹사이트와 USB로 연결하는 방법

1. Windows의 **Chrome**(또는 Edge 등 Chromium 계열)에서 공개 주소 `https://eunsaegim-dot.github.io/rose-garden/`를 엽니다.
2. UNO R3가 USB로 연결되어 있고, 2번 과정으로 펌웨어가 업로드된 상태인지 확인합니다.
3. 화면 우측 상단의 작은 **"⎋" 아이콘**을 클릭합니다. (Web Serial을 지원하는 브라우저에서만 보입니다.)
4. 브라우저가 띄우는 "연결할 장치 선택" 창에서 아두이노가 연결된 포트를 선택하고 "연결"을 클릭합니다.
5. 화면 하단에 "아두이노가 연결되었습니다" 안내가 잠깐 표시되고 아이콘이 분홍색으로 바뀌면 연결 성공입니다.
6. **중요**: 이 클릭(사용자 제스처)을 먼저 완료해야 합니다. 이 클릭이 USB 연결 승인과 동시에 브라우저의 오디오 자동재생 제한도 풀어주기 때문에, 물리 버튼을 누르기 전에 반드시 이 과정을 먼저 거쳐야 이후 음악이 정상적으로 소리를 냅니다.
7. 연결이 끊기면(케이블 분리 등) 하단에 안내가 뜨고, "⎋" 아이콘을 다시 클릭하면 재연결을 시도합니다.

## 4. 테스트 체크리스트 (전체 음악-진동 동기화 포함)

### 4-1. 버튼 1 (D7, 체감시간 측정)
- [ ] 버튼을 한 번 누르면 웹사이트의 "시간 느끼기" 버튼이 "지금 멈추기"로 바뀐다
- [ ] 버튼을 다시 누르면 측정이 종료되고 `/bloom` 페이지로 전환된다
- [ ] 측정 시작 시 LED(D11)가 켜지고, 종료 시 꺼진다

### 4-2. 버튼 2 (D8, 전체 음악 재생)
- [ ] 버튼을 누르면 온스크린 "음악 재생"과 동일하게 전체 장미 음악이 재생된다
- [ ] 재생 중 버튼을 다시 누르면 음악이 멈춘다
- [ ] 온스크린 "음악 재생" 버튼으로 시작/정지해도 물리 버튼과 동일하게 동작한다 (두 입력이 같은 로직을 공유하는지 확인하는 목적)

### 4-3. 전체 음악-진동 동기화
- [ ] 전체 음악 재생 중 진동 모터가 음의 리듬에 맞춰 켜지고 꺼진다
- [ ] 음 사이 쉬는 구간에서 진동이 멈춘다
- [ ] 음악이 끝까지 재생되면 진동도 함께 멈춘다
- [ ] 재생 중간에 (물리 버튼2 또는 온스크린) 정지하면 진동도 즉시 멈춘다

### 4-4. 연결 해제/재연결 및 하드웨어 독립성
- [ ] USB 케이블을 물리적으로 뽑으면 화면에 "하드웨어 연결이 끊어졌습니다" 안내가 뜬다
- [ ] 다시 꽂고 "⎋" 아이콘을 다시 누르면 재연결된다
- [ ] USB가 연결되지 않은 상태에서도 온스크린 버튼만으로 음악이 정상 재생된다 (하드웨어 없어도 웹사이트가 완전히 동작하는지 확인하는 목적)

## 5. 자주 발생할 수 있는 오류와 해결 방법

| 증상 | 가능한 원인 | 해결 방법 |
|---|---|---|
| IDE 업로드 시 "포트를 찾을 수 없음" | USB 드라이버 미설치, 케이블 불량, 다른 프로그램이 포트 점유 중 | 장치관리자에서 COM 포트 확인, 보드 드라이버 설치 확인, 케이블 교체, 다른 시리얼 프로그램 종료 후 재시도 |
| 업로드 중 "avrdude: stk500_getsync() 오류" | 보드/포트 선택 오류 | 보드를 "Arduino Uno"로, 포트를 올바른 COM으로 재선택 후 재시도 |
| Chrome에 "⎋" 아이콘이 안 보임 | Web Serial을 지원하지 않는 브라우저(Safari/Firefox 등) | Chrome 또는 Edge 최신 버전 사용 |
| 연결 창에 보드가 안 보임 | 다른 프로그램(Arduino IDE의 시리얼 모니터 등)이 포트를 점유 중 | 다른 시리얼 프로그램을 모두 종료한 뒤 재시도 |
| 연결은 됐지만 버튼을 눌러도 반응 없음 | 배선 오류(GND 미연결 등), 펌웨어 미업로드, 다른 코드가 올라가 있음 | 배선 재확인, 펌웨어 재업로드, Arduino IDE의 시리얼 모니터(9600 baud)로 버튼을 눌렀을 때 `BUTTON_1_TIME_MEASURE` 등이 실제로 출력되는지 직접 확인 |
| 음악은 나오는데 진동이 없음 | 모터 모듈 전원 미연결, IN 핀 로직이 반대, 모듈 불량 | 모듈 VCC/GND 재확인, 데이터시트의 활성 로직 확인(1번 "주의" 참고), 모듈 교체 테스트 |
| 소리가 전혀 안 남 | "⎋" 아이콘으로 연결을 완료하기 전에 물리 버튼을 먼저 누름 (브라우저 오디오 자동재생 정책) | 반드시 3번 절차의 "⎋" 아이콘 클릭을 먼저 완료한 뒤 버튼 사용 |
| 연결이 수시로 끊김 | USB 케이블/허브 불량, 전원 불안정 | 케이블 교체, PC 허브를 거치지 않고 본체 USB 포트에 직결 |

## 6. 검증 상태 — 전달 전 반드시 숙지해 주세요

- ✅ **확인됨**: `.ino` 코드가 `arduino-cli` + `arduino:avr:uno` 코어로 실제 컴파일에 성공함 (2026-10-18).
- ✅ **확인됨**: 웹사이트가 보내고 받는 명령 문자열(`BUTTON_1_TIME_MEASURE`, `BUTTON_2_PLAY_RESULT`, `VIBRATE_ON`/`VIBRATE_OFF`, `MEASURE_ON`/`MEASURE_OFF`)이 `.ino`와 정확히 일치함.
- ⚠️ **아직 검증되지 않음** (개발팀이 실제 보드/부품을 보유하지 않아 테스트 불가):
  - 실제 버튼 2개의 물리적 눌림이 30ms 디바운스로 깨끗하게 인식되는지
  - 실제 LED 배선(저항값, 극성)이 코드의 `digitalWrite(D11, HIGH/LOW)`와 맞는지
  - 실제 진동 모터 모듈의 전원 사양과 IN 핀 활성 로직이 코드의 가정(활성-HIGH, 듀티 200)과 맞는지
  - USB로 실제 보드와 Windows Chrome이 통신할 때의 지연·안정성, 케이블 재연결 동작
- 이 자료의 **4번 체크리스트**를 현장에서 실제로 수행해, 위 미검증 항목들을 하나씩 확인해 주시기 바랍니다.
